# Recomendador de Projetos Acadêmicos UFSM

Microsserviço Python para recomendação de projetos acadêmicos da Universidade Federal de Santa Maria.

## Objetivo

Desenvolver e avaliar um sistema de recomendação de projetos acadêmicos utilizando técnicas de machine learning, combinando filtragem baseada em conteúdo e filtragem colaborativa.

## Tecnologias

- Python
- FastAPI
- Scikit-learn
- Scikit-surprise
- Sentence Transformers
